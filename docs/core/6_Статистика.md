# Статистика и информация
## Обязательные поля для заполнения карточки по шаблону
```python
result = service.get_required_card_fields()
```

Возвращает ответ вида:
```
{
    'ИК-1': ['length_body', 'weight', 'sex', ...],
    'ИК-2': ['parent_male_id', 'parent_female_id', 'water_body_name', 'release_date', ...],
    'КВ-1': ['status', 'water_body_number', 'length_body', 'length_tail', ...],
    'КВ-2': ['status', 'water_body_name', ...]
}
```

## Статистика по видам особей.
```python
stats = service.get_species()
```

Возвращает ответ вида:
```
[
    {'prefix': 'K', 'name': 'Карелина', 'count': 88},
    {'prefix': 'R', 'name': 'Ребристый', 'count': 27}
]
```

## Последние n коммитов в базе данных.
Изменённые поля содержат значения. Неизменённые - `None`.
```python
commits = service.card_service.get_last_commits(2)
```

## Количество распознваний и обнуление счётчика распознаваний.
Не забудьте пересоздать базы данных перед использованием нового функционала.
```python
count = service.card_service.get_reid_count()
service.refresh_reid_count()
```
