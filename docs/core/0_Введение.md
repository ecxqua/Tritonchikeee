# Вход в ядро приложения.
В `docs/core/` описывается функциональность ядра приложения. Не вся функциональность в полной мере реализована в API-сервисе или в клиентском приложении. Проблемы и долги описаны в `docs/Техдолг.md` и в `issues` репозитория.

## Содержание
0. Введение. Инициализация сервиса.
1. Анализ
2. Карточки
3. История изменений карточки
4. Проекты
5. Управление загрузками
6. Статистика и информация

`service/identification_service.py` - единственный сервис, с которым можно полностью безопасно взаимодействовать
сторонним системам без ущерба логике приложения. Остальные сервисы доступны только в режиме для чтения (READ).
## Инициализация сервиса.

```python
from services.identification_service import create_identification_service, setup

# 1. Инициализация
setup(migrate=False)  # Подгрузка моделей, поднятие баз данных, идемпотентно
service = create_identification_service()

# Обнуление баз данных и перезагрузка
service.refresh(confirm=True)
```
