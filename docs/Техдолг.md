# Технический долг ядра:
* Кэширование хранилища эмбеддингов (неэффективное хранение: EmbeddingService)
* CardService: add_new_individual из-за изолированности транзакции бд повторяет код и выглядит грязно.
* identify_and_confirm выглядит как бесполезная оболочка. Скорее всего Uploads можно полностью вырезать, пока это legacy.
* История изменений не работает с фактом удаления фотографий (при удалении фотографии нет возможности что-либо восстановить по истории.)
* Тепловая карта неэффективна. Решения: смена решения или опциональная обработка тепловой карты после анализа.
    * К тому же сама тепловая карта должна помогать при сравнении особей. Нам не интересен просто факт того, что определённая область повлияла на формирование эмбеддинга. Нужно именно доказательное сравнение, по которому биологи смогут доверять нашей системе.
