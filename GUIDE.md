## Обзор
На странице доступны:
- просмотр общей статистики системы (количество проектов, особей, распознаваний)
- быстрый переход на основные страницы приложения (опознание, проекты, новая карточка)
- список последней активности в системе

## Опознание
Страница предполагает загрузку фотографии и (опционально) выбор фильтрации области поиска.

По окончании процесса опознания на странице будет выведен список потенциальных особей в порядке убывания вероятности, а также доступен просмотр тепловой карты для рассмотрения конкретных признаков, учтённых в процессе идентификации. Каждая особь в списке кликабельна и ведёт к её индивидуальной странице.

## Проекты
На странице предоставлен список всех проектов, подключённых к проекту.

Страница каждого индивидуального проекта содержит:
- общую информацию (название, вид, территория, описание)
- список кликабельных особей с общей информацией до перехода на страницу
- кнопка добавления новой особи
- кнопка редактирования проекта
- кнопка удаления проекта

## Особь
Страница особи содержит в себе всю информацию об особи, включая изображения (кропы), а так же возможность отредактировать или удалить особь. Внизу страницы можно найти историю редактирования.

## Новая карточка
Страница содержит форму с динамически выбранными (в зависимости от указанного типа карточки) полями и поле для загрузки фотографии. При сохранении у фотографии будет выделен кроп.

## Настройки
В настройках можно указать:
- путь до API
- количество особей, выводимых в список при распознавании
